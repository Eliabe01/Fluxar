# **App Name**: InterCopy Finances

## Core Features:

- Dashboard Overview: Dashboard with a clear overview of financial status, prominently displaying the current balance and recent transactions.
- Transaction Entry: Intuitive forms for quick transaction entry, including value, date, description, category, account, and payment method.
- Financial Reporting: Visual reports, using charts for income, outcome, and balance progression. Generative AI used as tool to select appropriate report visualization for any given data selection.
- Budgeting: Configurable budget limits for categories, with progress tracking and alerts.
- Balance Target: Allow tracking of balance targets.
- User profiles: User authentication and profiles

## Style Guidelines:

- Primary color: Orange (#F26419) for interactive elements, inspired by Banco Inter's branding, conveys energy and trustworthiness.
- Background color: Light gray (#F2F2F2) provides a neutral, clean backdrop that ensures legibility.
- Accent color: Blue (#4285F4) for highlighting key information and CTAs.
- Body and headline font: 'PT Sans' (sans-serif) for clear, modern typography; use for both headings and body text.
- Use a consistent set of minimalist icons throughout the application to represent different categories, actions, and settings. Icons should be simple, clear, and easily recognizable.
- Utilize cards and sections to group related information and functionalities. The dashboard should be well-organized, presenting key metrics and recent activities in a clear and visually appealing manner.
- Incorporate subtle animations and microinteractions to enhance the user experience. For example, smooth transitions between screens, visual feedback on button presses, and loading indicators.
