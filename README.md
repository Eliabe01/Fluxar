# 💰 InterCopy Finances (Fluxar)

Aplicativo de **gerenciamento financeiro pessoal** desenvolvido para controle de receitas, despesas e organização financeira, com interface moderna e foco em usabilidade.

O projeto foi construído utilizando **Next.js**, **React**, **Tailwind CSS**, **ShadCN UI** e **Firebase**, aplicando boas práticas de desenvolvimento frontend e integração com serviços em nuvem.

---

## 🚀 Funcionalidades
- Cadastro e visualização de receitas e despesas
- Organização financeira por categorias
- Interface responsiva e moderna
- Persistência de dados utilizando Firebase
- Deploy automatizado via Firebase Hosting

---

## 🛠️ Tecnologias Utilizadas
- **Next.js**
- **React**
- **Tailwind CSS**
- **ShadCN UI**
- **Firebase (Hosting e serviços de backend)**
- **Node.js**
